Il tuo patrimonio, senza abbonamenti.

Guida pratica dell’app gratuita accessibile dal web. Nessun account, carta di credito, database ospitato o API bancaria è necessario. Tutti i calcoli e le importazioni avvengono nel browser.

Da sapere prima di iniziare
Senza configurazione cloud, i dati stanno nel browser, non nel sito. Telefono e computer hanno copie indipendenti. Cancellare i dati del browser può cancellare il patrimonio: scarica regolarmente il backup JSON. «Nascondi importi» non cifra i dati.

1. Apri l’app, senza installare programmi

  1. Apri BauPatrimonio nel browser, sul computer o sul telefono. Non devi scaricare il repository, installare Node.js o usare il terminale.
  2. Scegli «Inizia il mio patrimonio» oppure «Prova con dati di esempio».
  3. Salva il sito nei preferiti. GitHub Pages distribuisce l’app; i tuoi importi non vengono salvati nel repository. Per l’archivio online segui la sezione Supabase più sotto.

2. Installazione facoltativa sul telefono

  1. Apri il sito con Chrome o Safari.
  2. Chrome: menu → «Installa app». Safari: Condividi → «Aggiungi alla schermata Home».
  3. Attendi la prima apertura online completa, poi puoi utilizzare l’app anche offline.

Non devi creare workflow o account sviluppatore per usare il sito. La pubblicazione dei file statici è gestita dal manutentore tramite la cartella docs/.

3. Inserisci il tuo primo conto

  1. Scegli Inizia il mio patrimonio. I dati di esempio non vengono copiati.
  2. Aggiungi voce → Conto corrente e liquidità.
  3. Inserisci nome, saldo contabile, valuta e data → Salva. Disponibilità e somme vincolate sono dettagli dello stesso saldo, non voci da sommare.
  4. Per immobili e debiti inserisci valore totale e la tua quota. La quota del mutuo può essere diversa da quella della casa. Se non conosci un valore, spunta «Valore non ancora disponibile»: il totale sarà dichiarato parziale.

4. Leggi e prova gli insight

  1. In Panoramica scegli il periodo e il formato Gradini / Linee / Colonne. Puoi confrontare il netto oppure attività e debiti. Tocca un punto o usa Tab e frecce per leggerne la data.
  2. La composizione è disponibile come Anello / Barre / Tabella, per categoria, istituto o natura/liquidabilità.
  3. Apri Leggi tra i numeri, scegli due date e prova Cascata / Variazioni / Tabella. La cascata è sospesa se mancano valori. Su telefono scorri il singolo grafico dove necessario; la tabella resta l’alternativa leggibile.
  4. Esporta il grafico in SVG (vettoriale), PNG (immagine) o i dati in CSV. Con gli importi nascosti gli export sono bloccati. In formato Tabella è disponibile il CSV.
  5. Per esplorare grafici già popolati, torna alla copertina dal Profilo → Prova con dati di esempio → «Prova i grafici con sei mesi di storico dimostrativo». Quello storico è dichiaratamente inventato e resta nella sola demo.

5. Importa file e registra operazioni

  1. Aggiungi prima la voce destinataria. Vai in Fonti → Importa saldi o posizioni oppure Importa movimenti.
  2. Scarica uno dei tracciati di esempio dell’app: saldi, posizioni, movimenti. Non sono tracciati ufficiali Fideuram o Trade Republic.
  3. Abbina colonne, conto, valuta e separatore; controlla l’anteprima. Per il dettaglio strumenti spunta posizioni e abbina anche nome/descrizione, quantità e prezzo. Non includere righe totale insieme ai componenti.
  4. I movimenti non modificano automaticamente i saldi. Per un trasferimento tra due conti tuoi usa Patrimonio → Trasferisci.
  5. Per un acquisto o una vendita già eseguiti, oppure per un rimborso di capitale, usa Patrimonio → Registra operazione. Capitale, commissioni e interessi vengono distinti. Non vengono inviati ordini o pagamenti; questa procedura è limitata a posizioni EUR.

6. Usa gli stessi dati su due dispositivi

  1. Sul dispositivo aggiornato: Profilo in alto a destra → Scarica backup strutturato.
  2. Trasferisci il JSON con un mezzo sotto il tuo controllo (per esempio cavo, AirDrop o condivisione locale). Il JSON contiene dati finanziari in chiaro: non metterlo nel repository o in un link pubblico.
  3. Sull’altro dispositivo scegli il patrimonio personale → Profilo → Ripristina backup JSON. Conferma la sostituzione solo dopo aver esportato eventuali modifiche locali da conservare.
  4. Non modificare contemporaneamente entrambe le copie: non esiste fusione o sincronizzazione automatica. Il backup demo si ripristina solo nella demo, quello personale solo nell’archivio personale.

Archivio online con Supabase, senza Node.js

Il collegamento cloud è implementato ma non attivato su un progetto reale. L’attivazione si svolge interamente dal browser. Non usare il database di BauSplit: crea un progetto dedicato per evitare modifiche ad altre app.

  1. Accedi alla dashboard Supabase e crea un progetto in un’organizzazione sul piano Free ($0), preferibilmente in una regione UE. Non selezionare Pro, add-on, PITR o upgrade. Conserva la password database privatamente: non serve inserirla nell’app.
  2. Il piano Free indica massimo due progetti attivi: se hai già raggiunto il limite, fermati, non attivare un piano a pagamento. Il provider può sospendere i progetti inattivi; puoi riattivarli dalla dashboard. Condizioni e limiti ufficiali, consultati il 19 novembre 2026.
  3. Nel progetto NUOVO apri SQL Editor → New query. Apri su GitHub il file SQL di BauPatrimonio, copia tutto il contenuto e premi Run nell’editor Supabase. Eseguilo una sola volta. Deve riuscire senza errori; non disattivare Row Level Security.
  4. In Authentication → Users → Add user → Create new user crea il tuo utente con email e password personale; usa la conferma prevista dalla dashboard. Non inviare queste credenziali in chat. Puoi disabilitare le nuove registrazioni pubbliche nelle impostazioni Auth: è un’app personale.
  5. Da Connect / Project Settings → API Keys copia il Project URL e soltanto la chiave publishable oppure la vecchia anon. Non usare mai secret o service_role.
  6. Apri il tuo patrimonio nell’app → Profilo → Il tuo archivio online. Espandi la configurazione, inserisci URL e chiave pubblica, poi accedi con l’utente Auth creato sopra.
  7. La prima volta conferma e scegli Crea il primo salvataggio online. Se l’archivio remoto esiste già, l’app non lo sovrascrive: scegli Apri / rileggi archivio online. Questa azione sostituisce la copia visualizzata, non unisce dati.
  8. Le modifiche successive vengono inviate al cloud, mantenendo una copia nel browser. Sul telefono o dopo un ricaricamento accedi e apri l’archivio online prima di modificare. La sessione resta solo in memoria e scade; non è sincronizzazione realtime. Non modificare due copie contemporaneamente.

Un conflitto, una sessione scaduta o un errore di rete non sovrascrivono il cloud: l’app conserva la copia locale e segnala l’errore. Prima di rileggere il cloud riconcilia le modifiche rimaste solo locali: la rilettura le sostituisce. Il progetto cloud non è un backup garantito; il piano Free può essere sospeso e non offre la stessa conservazione dei piani a pagamento. Nessun promemoria di backup è attivato.

Grafici del solo portafoglio e rendimento

In Insight scegli Investimenti: andamento, composizione e confronto includono tutti gli investimenti insieme, senza liquidità, pensione, case o debiti. I dettagli del dossier non vengono contati due volte. Apri «Leggi tra i numeri» per confronto tra date e qualità dei dati.

Il rendimento usa Modified Dietz, non annualizzato, e viene mostrato solo dopo conferma della completezza dei flussi. Servono valutazioni di tutti gli investimenti nelle due date e flussi EUR della tua quota. Acquisti e vendite registrati ora includono i costi; i movimenti precedenti o importati non vengono classificati automaticamente. Le opzioni «Flussi e metodo di calcolo» consentono di classificarli e aggiungere flussi mancanti senza modificare i saldi. Flussi fra due investimenti si compensano, non sono ingressi netti. Non duplicare acquisti o vendite già registrati.

La percentuale non è un rendimento certificato o fiscale: include soltanto costi, imposte e proventi effettivamente rappresentati nei dati. Archiviazioni nel periodo, dati mancanti o capitale ponderato non positivo impediscono il risultato o la percentuale. L’app non inventa un rendimento da una semplice differenza di valore.

7. Banche: cosa è stato verificato

Verifica delle fonti ufficiali: 19 novembre 2026. Fideuram dispone di un percorso PSD2 tramite CBI Globe; Trade Republic documenta un’API AIS per conti, saldi e movimenti. Enable Banking documenta Fideuram in Italia e Trade Republic anche per clienti italiani. Queste evidenze non certificano un conto specifico né il funzionamento dell’integrazione nell’app: nessun connettore è attivo o collaudato.

I termini di Enable Banking consentono l’uso gratuito personale, limitato ai propri conti collegati in modalità restricted. Occorrono registrazione, applicazione personale, chiave privata e consensi sul sito della banca/provider. Non inserire tali chiavi nel sito, nel repository o in chat.

GitHub Pages da solo non è un backend bancario. Per automatizzare l’accesso servirebbe un servizio server riservato aggiuntivo. Non è stato attivato. L’archivio Supabase descritto sopra salva i tuoi dati, ma non implementa ancora il connettore bancario. Le posizioni titoli, ETF e previdenza non risultano coperte dalle API AIS consultate. Restano disponibili subito manuale e CSV. Il dettaglio di fonti e limiti è nella sezione Fonti dell’app.

La valuta di riferimento resta EUR. Non sono presenti quotazioni live, import PDF/XLSX o sincronizzazione realtime. Il sito online non implica da solo che i dati siano salvati online: occorre configurare Supabase e aprire l’archivio dal Profilo su ogni dispositivo.

La pubblicazione del codice e della demo non pubblica i tuoi dati. Non sono stati attivati progetti Supabase, conti reali o abbonamenti dall’agente. GitHub Pages risulta attivo sulla cartella docs del branch corrente.
